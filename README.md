## Skill Level: Intermediate

This project demonstrates a structured intermediate-level approach to banking analytics, combining Python, risk modeling logic, portfolio analysis, and business interpretation.

## Overview

This project builds an end-to-end retail banking credit risk analytics workflow focused on default prediction, portfolio risk understanding, and expected loss estimation under Basel II/III and IFRS 9 frameworks.

## What This Project Covers

- Credit risk data preparation
- Feature engineering and WOE-based risk analysis
- Probability of default (PD) modeling
- Expected loss (EL) estimation
- Stress testing and risk monitoring
- Business insights for lending decisions

## Tools and Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Business Outcomes

- Risk scorecard development
- Default segmentation and borrower analysis
- Portfolio-level expected loss assessment
- Macro stress scenario evaluation
- Regulatory-ready risk reporting framework
